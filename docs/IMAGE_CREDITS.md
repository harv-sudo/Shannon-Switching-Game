## Existing project graphics

`images/desktopIcon.svg` and `images/shannonGameIcon.svg` are existing Inkscape assets added by Griffia in commit `ed9e4f2`, before the recent UI updates. They were not created with the image-generation tool during those updates.

The menu networks and board decorations are drawn at runtime by GDScript (`networkArt.gd`, `boardBackdrop.gd`, and the node/edge drawing code). They are not image-model assets.

## Image policy

Do not use image-generation models for this project. Source any new image assets from the internet with a verified license permitting the intended use, and record the author, source, license, and any modifications here. The former AI-generated `docs/cover.png` has been removed.
